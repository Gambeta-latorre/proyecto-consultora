# Berasoft S.R.L. + ASHAB

Proyecto final 7°2 · E.E.S.T. N°4 Berazategui · **Juan Cruz Ceresani**

**Berasoft S.R.L.** es una empresa de desarrollo web. Su cliente es **ASHAB**, una marca de yerba mate argentina que vende por menor y por mayor.
Los pedidos y consultas se hacen con un **botón de WhatsApp** que abre el chat con el mensaje ya escrito. Los dos sitios tienen **inicio de sesión**: en ASHAB los clientes se registran y quedan guardados en MySQL (XAMPP) y ven el precio por mayor; en Berasoft el socio entra a su panel.
Están hechos solo con **HTML, CSS y PHP**, sin JavaScript. ASHAB usa una base **MySQL** con dos tablas: `productos` y `usuarios`.
