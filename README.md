# Berasoft S.R.L. + Veterinaria Patitas Felices

Proyecto final 7°2 · E.E.S.T. N°4 Berazategui · **Juan Cruz Ceresani**

**Berasoft S.R.L.** es una empresa de servicios informáticos de Berazategui que desarrolla sitios web para comercios.
Su cliente es **Veterinaria Patitas Felices**: Berasoft le hizo un sitio con turnos online para perros, gatos, ovinos y bovinos.
Los dos sitios están hechos solo con **HTML, CSS y PHP**, sin JavaScript. Patitas Felices además usa una base **MySQL**.

## Sitios publicados

| Sitio | Dirección |
|---|---|
| Berasoft S.R.L. | https://rumboglobal.vercel.app |
| Veterinaria Patitas Felices | https://ashab-omega.vercel.app |

Las direcciones conservan el nombre de la versión anterior. Se cambian en Vercel, en *Settings > Domains* de cada proyecto (por ejemplo, `berasoft.vercel.app` y `patitasfelices.vercel.app`).
